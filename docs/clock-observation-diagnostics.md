# 시계 관측 실패 진단과 불완전 감시 거부

2026-11-19 · 개인 qualification 하네스 전용 변경.

## 해결하는 문제

직전 장애·복구 대조 실행은 기능 시험과 최종 SQL 대조가 통과했지만, 239개 시계 기록 중 1회가 `clock_sample_failed`였다. 기존 기록에는 실패 시각·단계·예외 종류가 없어 연결 시간 초과, SQL 오류, 다른 원인을 구분할 수 없었다. 그 실행의 환경 검증 실패와 종료 코드 1은 유지한다.

새 진단은 다음 관측에서 원인을 구분할 정보를 남긴다. 과거 실패의 원인을 소급해서 확정하거나 해결했다고 주장하지 않는다.

| 항목 | 기록 범위 |
|---|---|
| 관측 지점 | 시작 `start`, 고정 주기 `periodic`, 종료 `stop` |
| 실패 단계 | 연결 `connect`, 조회·결과 읽기 `query`, 연결 종료 `close`, 시간 비교 `validate` |
| 시각·시간 | 호스트 시작·종료 UTC, monotonic 기준 소요 ms |
| 오류 종류 | 설치된 psycopg가 정의한 예외 클래스 이름만 허용 |
| SQLSTATE | 알려진 드라이버 클래스의 5자리 영숫자 코드만 허용 |
| 불명확한 예외 | `PsycopgError` 또는 `UnexpectedSamplerError`로 분류 |
| 미기록 | 오류 메시지·repr·args·diag·pgconn·DSN·호스트명·키 경로·토큰·비밀번호 |

SQLSTATE나 예외 종류는 진단용이다. 인증·승인·시간 유효성·실행 권한의 근거로 사용하지 않는다. 관측 실패를 실제 시차 초과로 바꿔 표시하지도 않는다.

## 실패를 다루는 방법

- 시작 관측 실패는 기록한 뒤 예외를 전달한다. 작업을 시작하지 않는다.
- 주기 관측의 DB 오류는 같은 관측에서 재시도하지 않는다. 실패를 보존하고 다음 기존 주기에서 별도의 관측을 수행한다. 이후 성공해도 전체 검증은 실패다.
- 예상 밖 예외가 감시를 끝내면 해당 실패를 보존한다. 이전 정상 기록만으로 통과하지 않는다.
- 종료 관측 실패도 `clock_checks`에 남기고 전체 검증을 실패시킨다.
- 기존 5초 join 뒤 스레드가 끝나지 않았다면 불완전 감시로 거부한다. 동시에 새 종료 조회를 시작하지 않는다.

관측 간격 0.5초, DB 연결 제한 2초, 허용 시차 하한 1초, 종료 join 5초는 유지한다. 제품·이미지·승인·복구 조건·클라이언트 재시도 및 완료 기한은 변경하지 않는다. 새 필드는 하네스 보고서 버전 2에 추가하며 기존 `samples`, `passed`, `max_allowed_skew_seconds`도 유지한다.

## 검증

단위 시험은 비밀이 포함된 예외 메시지와 임의 클래스 이름이 기록되지 않는지, 시작·종료·주기 실패와 미종료 스레드가 성공으로 바뀌지 않는지 확인한다. 실제 전용 TLS DB에서는 정상 관측, 잘못된 호스트명 연결 거부, 의도적으로 주입한 `SELECT 1/0`의 실제 SQL 오류를 검증한다. 마지막 오류는 진단 동작 시험이며 과거 원인 재현이 아니다.

```sh
python tests/qualification_postgres.py --suite clocks \
  --image sha256:0d938e975177bef9f1f61f3f9dbcf2e0aa0a139568f66d3415ed8892eb97f6ac \
  --security-source <pinned-security-checkout>/src --artifacts <new-private-directory>
```

새 비공개 출력 경로와 고정 security checkout을 사용한다. 공유 클러스터·클라우드·고객 자원을 사용하지 않는다. 진단 개선만으로 무중단·시계 정확성 SLO·금융 보안 인증을 발급하지 않는다.

이번에는 단위·실제 DB 시험 13건이 통과했고, 새 작업자 장애 대조의 시계 관측 198회도 모두 통과했다. 해당 대조에서 최종 주문은 SQL 103/103건이었지만 최초 오류 15건과 최대 부하 주문 완료 약 21.751초는 유지한다. 과거 1회 관측 실패의 원인이 해결됐다는 의미는 아니다.
