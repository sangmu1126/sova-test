# 이전 운영 자격 재검토 · 2026-11-18

## 요청과 판단

사용자가 팀 플랫폼과 개인 Sova의 무중단 이전이 실제로 프로덕션급인지 검토하고, 그 고민과 앞으로의 방향도 기록하도록 요청했다.

결론은 안전한 이전을 위한 구현과 제한된 실측이 존재하지만, 서비스 전체의 무중단 운영 자격은 별도 증명이 필요하다는 것이다. 이전 주담당 여부와 개인 기여도도 구분한다. T14·T19, 관측 T36·T37, 콘솔·앱 T21·T22는 이전의 안전·판단·연결 복구에 기여하며 DB 복제·실행기만이 이전 전체는 아니다.

## 확인 기준

- 개인 Sova: `03c4839a43551e303ebf3347021e926fce2d1274`.
- 팀 platform: `61d44b1d042e5524c15e46330f60ccaf3733a64f`.
- 참조: 실행기 runner/store/DB 원격 adapter, 기존 업무 fixture, 로컬·클라우드 정지 구간 시험, 운영 서비스·probe ADR, 구현·실측 문서.
- 이 기록 작성 중 존재하던 MongoDB 어댑터·시험의 미커밋 변경은 이번 문서 커밋에 포함하지 않는다.

## 반영

- [ADR-0008](../adr/0008-migration-production-qualification.md): 기능 확대보다 첫 경로의 서비스 연속성·복구 자격을 다음 통합 우선순위로 정했다.
- [검토·후속 계획](../migration-production-qualification.md): 지원 범위, 요청 대조, 장애표, 보안 조건, 증거 묶음과 MQ-01~06을 정리했다.
- 문서 목차와 기존 로드맵에서 새 우선순위로 이동할 수 있게 했다. 과거 로드맵은 삭제하거나 최신 완료 상태로 다시 해석하지 않는다.

## 이번 검증과 미검증

이번 변경은 문서다. 문서 5개의 상대 링크 97개와 참조한 시험 파일의 존재를 확인했고 오류는 0개였다. `git diff --check`도 통과했다. 실행 코드·CI·운영 설정은 바꾸지 않는다. 새로운 클라우드 시험·침투시험·성능 측정·SLO 승인·운영 자격 발급을 하지 않았다. 외부 공식 문서의 일반 원칙은 내부 구현 완료의 증거로 사용하지 않는다.

다음 개발 단위는 기존 주문 시험을 실제 HTTP 경로에 연결할 수 있는지 조사하고, 요청 원장과 영속 결과의 대조를 구현하는 MQ-01/02다. 기존 DB 직접 쓰기 시험을 사용자 서비스의 통과로 옮기지 않는다. 허용 지연·오류·복구 수치는 아직 확정하지 않았다.
