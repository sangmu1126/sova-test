# 개인 이전 경로의 공개 가능한 검증 요약 — 2026-11-20

이 문서는 코드 변경과 검증 범위를 설명하는 비식별 요약이다. 실제 자원 식별자, 접속 정보, 시험 계정 식별자, 비용 금액, 운영 화면과 원본 실행 기록은 공개하지 않는다. 원본은 비공개 로컬 기록과 공개하지 않은 Git commit에 보존했다. 이 요약 자체를 외부의 독립 검증이나 운영 자격 증명으로 사용하지 않는다.

## 실제로 확인한 범위

| 범위 | 결과 | 확대하지 않는 주장 |
|---|---|---|
| 실제 개인 AWS·소유 로컬 VM 연결 | 앱·DB TLS 4경로, 미허용 포트 3개 거부, 기존 데이터 보존 | 원래 앱의 이전 완료가 아님 |

| 실제 분리 DB·Service 시험 | forward 7·reverse 8단계, 재호출·새 인스턴스 조회, 대상 신규 쓰기의 복귀 후 보존 | 실제 원래 앱의 접수 계획이나 무중단 E2E가 아님 |

## 구현 변경

- 재개한 개인 시험 환경에서 기존 host-only 운영 연결 복원과 TLS 갱신을 분리했다. 소유권·세대·Service UID·resourceVersion을 확인하고 원래 backend·이미지·경로 선택을 보존한다.
- 시험 IdP는 고정 upstream 이미지의 사전 build와 공식 startup realm import를 명시적으로 선택한다. 계정 입력은 소유 비root 컨테이너의 tmpfs에 stdin으로 전달하며, master 관리자 토큰 없이 실제 PKCE·JWT·역할 경계를 시험한다.
- 요구사항을 그대로 유지한 새 계약 revision을 CAS 등록한다. 만료된 서명의 기한을 수정하거나 같은 digest에 모호한 중복 서명을 발행하지 않는다.
- 콘솔은 서버 보류 이유를 읽을 수 있는 한국어와 다음 확인 작업으로 표시한다. 기존 코드·추가 근거도 확인할 수 있으며 알 수 없는 이유를 통과로 바꾸지 않는다. 이전 앱/사용자의 결과를 다른 범위에 표시하지 않는다.
- SQL 조사에는 read-only/repeatable read, 질의·잠금 제한과 결과 건수 상한을 둔다. 시퀀스 권한·역할 전환·관리 함수·제어 단위 메타데이터를 관측하되 credential 소유자와 외부 제어 경로의 완전성을 추정하지 않는다.
- 개인 개발 브랜치의 Python 3.11·3.14 및 콘솔 CI를 연결했다. 과거 고정 회귀 소스는 같은 commit이 존재하는 개인 저장소를 사용하며 팀 저장소를 변경하지 않는다.

## 검증 구분

- 로컬 Python 3.12.16: 전체 단위 시험 **1,342개 통과, 22개 조건부 제외**. 의존성 deprecation 경고 1개를 보존했다.
- 콘솔: **77개 통과**, 타입·production bundle·formatter 검사 통과.
- 전체 `src`·`tests` Ruff 및 고정 명세의 크기·SHA 검사 통과.
- 별도의 실제 브라우저·DB·권한/시간 제한 결과는 위 표 범위에 한한다. 서로 다른 환경의 숫자를 하나의 전체 운영 PASS로 합치지 않는다.
- 새 원격 CI는 실행 결과를 확인하기 전까지 통과로 기록하지 않는다.

## 남은 것

**여섯 단계 전체 완료가 아니다.** 원래 앱의 실제 이전은 접수하지 않았다. 완전한 writer/controller 경로, 외부 변경 수집의 보증, 데이터 항목별 위치 증거와 실행용 검증자 신뢰 인수가 먼저 필요하다. 이후 같은 실제 계획에서 승인·워커 실행·신규 쓰기·복귀·연속 서비스와 전체 콘솔 흐름을 인수해야 한다.

실제 모델 호출과 VM 우선순위 변경은 사용자의 보류를 유지했다. 실제 공격 침투시험이나 기업 금융 운영 자격을 수행했다고 주장하지 않는다.

공식 도구 실행 방식: [Keycloak 컨테이너 사전 build](https://www.keycloak.org/server/containers), [startup realm import](https://www.keycloak.org/server/importExport).
