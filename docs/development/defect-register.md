# 결함 목록 (2026-11-17 ~ 19)

이 기간에 찾아서 고친 결함을 한곳에 모았다. 자세한 경위는 [개발 기록](contract-foundation-2026-11-14.md)에, 기능 설명은 [구현 안내](../contract-foundation.md)의 각 절에 있다. 커밋은 `feature/contract-driven-foundation` 브랜치의 것이다.

**용어.**

- **판정 불가**: probe가 "쓸 수 있다/없다"를 가리지 못한 경우. [ADR-0007](../adr/0007-probe-design-principles.md)에 따라 실패 쪽으로 센다.
- **결함 주입**: 고친 코드를 일부러 되돌리거나 망가뜨려 시험이 실패하는지 확인한 것.

## 운영 결함: 정확성·안전

인계가 잘못 진행되거나, 증거가 틀리거나, 인계가 멈출 수 있던 결함이다.
