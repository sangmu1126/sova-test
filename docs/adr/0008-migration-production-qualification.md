# ADR-0008 · 이전 기능 확대와 운영 자격을 분리하고, 첫 경로의 서비스 연속성을 우선 검증

- 날짜: 2026-11-18
- 상태: 개인 개발 우선순위로 채택. 운영 SLO·지원 자격·공용 환경 변경은 승인하지 않음.
- 관련: [통합 명세 채택](0001-contract-driven-foundation.md), [정지 구간 검증](0004-verification-inside-the-window.md), [운영 서비스](0005-operational-service.md), [probe 원칙](0007-probe-design-principles.md).
- 상세: [프로덕션 자격 검토와 후속 계획](../migration-production-qualification.md).

## 배경

사용자가 팀 플랫폼과 개인 Sova의 무중단 이전 구현을 기업 운영 기준으로 재평가하고, 고민과 다음 방향을 기록하도록 요청했다. 두 코드베이스 모두 실행 순서·판정·쓰기 차단·복구를 갖추고 있지만, 구성 요소의 성공과 서비스 전체의 운영 자격을 같은 뜻으로 쓸 수 없다.

현재 개인 개발은 PostgreSQL 외의 저장소·계정·비밀·파일·세션으로 확대됐다. 지원 대상이 늘어도 사용자 요청의 완료·중복·유실, 실제 보안 설정 아래의 연속성, 실패 뒤 복구 시간을 입증한 것은 아니다. 기존 시험은 계속 유용하지만 서로 다른 코드·프로필·환경의 PASS를 합산해 하나의 운영 자격으로 만들지 않는다.

## 결정

1. 다음 통합 목표는 기존 HTTP 주문 시험과 PostgreSQL 인계 경로의 **사용자 요청부터 완료 결과까지**다. 새 업무 앱이나 새 복제 엔진을 먼저 만들지 않는다.
2. 출발지는 기존 AWS 컨테이너 앱·RDS PostgreSQL, 목적지는 독립 Linux VM의 앱·PostgreSQL을 목표로 한다. 먼저 일회용 로컬 환경에서 같은 실행 경로를 확인한 뒤, 허가된 전용 클라우드 경로에서 인수한다. 이 결정으로 새 자원을 만들거나 공유 서비스·권한·트래픽을 변경하지 않는다.
3. 신규 자격 대상은 일단 단일 PostgreSQL 쓰기 권한 단위, 등록된 앱·배치 writer, 명시된 데이터·업무 불변식으로 제한한다. 실제 관리형 failover·복원·다중 노드까지 지원하려면 해당 토폴로지를 별도로 고정하고 시험한다.
4. 데이터 안전성, 사용자 연속성, 보안 통제, 복구를 각각 판정한다. 어느 하나의 PASS도 나머지를 대신하지 않는다.
5. 사용자 연속성 측정은 실행기 내부의 쓰기 정지 시각과 별도로 수집한다. 재시도 후 성공해도 최초 실패·재시도·총 대기 시간을 보존한다. 처리 결과를 모르는 요청은 성공으로 추정하지 않는다.
6. 기능 수보다 이 경로의 증거와 결함 수정을 우선한다. 새 어댑터는 기존 작업을 버리지 않고 별도 후보로 유지한다. 새 데이터 종류 때문에 필요한 결함 수정은 계속하되, 운영 자격 경로에 자동 편입하지 않는다.
7. 기존 원장·승인·보안 보류·서명 근거·복제 adapter·probe·OTel을 재사용한다. 성능을 위해 보안 정책·독립 검증·최종 정합성 확인을 생략하지 않는다.
8. 계획된 이전의 RPO와 출발지 파괴 장애의 RPO를 구분한다. 논리 복제와 경계 비교만으로 미전달된 승인 쓰기의 재해 복구를 보장한다고 쓰지 않는다.

## 검토한 대안

| 대안 | 판단 |
|---|---|
| 저장소·클라우드·배포 대상부터 계속 확대 | 이식 범위는 넓어지지만 운영 자격의 부족을 해결하지 못한다. 다음 통합 우선순위에서는 뒤로 둔다. |
| 처음부터 양방향 쓰기·분산 합의 시스템으로 교체 | 업무 충돌·외부 효과까지 책임져야 한다. 현재 단일 writer 인계에 필요한지 입증되지 않아 선택하지 않는다. |
| 요청을 무조건 큐에 넣어 오류를 숨김 | 기한·취소·승인 순서·멱등성과 재시작 후 보존이 없으면 새 위험이다. 업무 계약상 허용할 때만 별도 전략으로 검증한다. |
| 기존 경로의 안전·연속성·복구를 고정 조건에서 검증 | 현재 자산을 가장 많이 재사용하면서 제품의 신뢰도를 직접 높인다. 선택한다. |

## 결과와 재검토 조건

당분간 기능 폭의 증가가 느려질 수 있다. 대신 어떤 규모·방향·실패 모델에서 무엇을 보장하는지 명확해진다. 첫 경로가 자격을 얻으면 같은 시험 계약으로 다른 어댑터를 검증한다. 보장을 유지할 수 없는 대상은 별도 프로필로 남긴다.

이 ADR은 운영 투입·금융 규제 준수·무중단 완료 선언이 아니다. 서비스 책임자가 허용 지연·오류·복구 조건을 정하고, 고정 릴리스의 인수 증거가 그 조건을 충족해야 지원 자격을 발급할 수 있다. 실제 트래픽의 요구가 짧은 쓰기 정지로 충족되지 않으면, 그때 버퍼링·증분 검증·다른 데이터 전략의 비용과 위험을 비교해 후속 ADR로 결정한다.
